# 安全

> 狀態：草稿

- 單一功能的做法寫在該功能的 spec，這裡只放連結
- 撰寫程式參考 ISO 27002:2022 與 OWASP ASVS Level 1

## 1. 原則

- 對外服務一律 HTTPS
- 除了登入，所有 `/api/**` 都要帶有效的登入憑證；是否登入一律由後端檢查，前端只決定畫面怎麼顯示
- 密碼、簽章密鑰等機密從環境變數讀取，不寫在程式與文件裡
- 病患資料一律虛構，種子資料與測試資料也一樣，不使用真實個人資料

## 2. 帳號與密碼

- 密碼雜湊後儲存
- 做法見[登入 spec](specs/auth/login/spec.md) §5

## 3. 登入憑證

- 憑證不能被前端 JavaScript 讀取：XSS 偷不走
- 要防 CSRF
- 只經由 HTTPS 傳送
- 登出時要清除憑證
- 做法見[登入 spec](specs/auth/login/spec.md) §5

## 4. 網路

- 資料庫不對外開放
- 只開放對外服務需要的連接埠；管理用的連線（SSH）限制來源 IP
- 各環境的實際設定見 [devops/](devops/README.md)
