# 病患

> 狀態：定案

## 1. 目的

- 護理師新增病患，並從列表用病歷號找到病患

## 2. 需求

### REQ-PAT-001 病患列表

- 列出病歷號與姓名，最新新增的在最上面，每頁 20 筆

- **AC1 列出病患**〔後端、E2E〕：Given 已有病患 When 開啟病患列表 Then 顯示病歷號與姓名，最新新增的在最上面
- **AC2 分頁**〔後端、E2E〕：Given 病患超過 20 筆 When 開啟病患列表 Then 每頁顯示 20 筆與總筆數，可以換到其他頁
- **AC3 頁碼超過最後一頁**〔E2E〕：Given 病患有 2 頁 When 開啟第 5 頁的網址 Then 顯示第 2 頁
- **AC4 沒有病患**〔E2E〕：Given 沒有任何病患 When 開啟病患列表 Then 顯示「目前沒有病患」

### REQ-PAT-002 搜尋病歷號

- 輸入病歷號的一部分，按 Enter 或「搜尋」後列出符合的病患

- **AC1 部分符合**〔後端、E2E〕：Given 有病歷號 A001、A002、B001 When 搜尋「a00」 Then 只列出 A001、A002；不分大小寫
- **AC2 搜尋後回到第 1 頁**〔E2E〕：Given 在列表的第 2 頁 When 搜尋 Then 顯示符合結果的第 1 頁
- **AC3 保留搜尋條件**〔E2E〕：Given 已搜尋並換到第 2 頁 When 重新整理 Then 仍然是同樣的搜尋條件與頁碼
- **AC4 清除搜尋**〔E2E〕：Given 已搜尋 When 按「清除」 Then 輸入框清空，列出所有病患的第 1 頁
- **AC5 找不到**〔E2E〕：Given 沒有符合的病患 When 搜尋 Then 顯示「找不到符合的病患」

### REQ-PAT-003 新增病患

- 在對話框輸入病歷號與姓名後新增

- **AC1 新增成功**〔後端、E2E〕：Given 已搜尋或在其他頁 When 輸入病歷號與姓名後送出 Then 關閉對話框，清除搜尋並回到第 1 頁，新病患在最上面
- **AC2 病歷號存成大寫**〔後端〕：When 輸入病歷號「a001」後送出 Then 存成「A001」
- **AC3 欄位空白**〔後端、E2E〕：When 病歷號或姓名沒填就送出 Then 該欄位顯示必填提示，不送出；不經畫面直接送出空白資料時被拒絕
- **AC4 超過字數**〔後端、E2E〕：When 病歷號輸入超過 20 個字或姓名超過 50 個字 Then 輸入框不接受超過的字；不經畫面直接送出超過字數的資料時被拒絕
- **AC5 病歷號格式**〔後端、E2E〕：When 病歷號含英文字母與數字以外的字 Then 病歷號欄顯示「病歷號只能是英文字母與數字」，不送出；不經畫面直接送出時被拒絕
- **AC6 病歷號已存在**〔後端、E2E〕：Given 已有病歷號 A001（包含已刪除的病患）When 新增病歷號「a001」 Then 病歷號欄顯示「病歷號已存在」，不新增

## 3. API

| 方法 | 路徑 | 用途 | 對應 REQ |
|---|---|---|---|
| GET | `/api/patients` | 病患列表、搜尋病歷號 | PAT-001、PAT-002 |
| POST | `/api/patients` | 新增病患 | PAT-003 |

- 分頁的參數與回應格式見 [conventions.md](../../conventions.md) §1.9

## 4. 畫面

### 病患列表 `/patients`

- 版型：側邊欄版型
- 入口：側邊欄的「病患列表」；登入後的預設頁

```
[🔍 搜尋病歷號      ] [搜尋] [清除]        [＋ 新增病患]

┌────────────────────────────────────────────────────┐
│ 病歷號          姓名                               │
│ A0057           陳測試                             │
│ A0056           林範例                             │
│ …                                                  │
└────────────────────────────────────────────────────┘
共 57 筆                      < 上一頁  [1] 2 3  下一頁 >
```

- 手機上「新增病患」放在搜尋框上方、靠右

#### 欄位

| 欄位 | 類型 | 必填 | 限制 | 行為 |
|---|---|---|---|---|
| 搜尋病歷號 | `SearchBox` | 否 | 最多 20 個字 | （REQ-PAT-002） |
| 新增病患 | `Button` | — | — | 開啟新增病患對話框 |

### 新增病患對話框

- 版型：對話框
- 入口：病患列表的「新增病患」

```
┌──────────────────────────────┐
│ 新增病患                   ✕ │
│                              │
│  ┌────────────────────────┐  │
│  │ ⚠ 請修正標示的欄位      │  │  ← FormAlert，有錯時才顯示
│  └────────────────────────┘  │
│  病歷號                      │
│  [                        ]  │
│    病歷號已存在              │  ← 欄位錯誤
│  姓名                        │
│  [                        ]  │
│                              │
│              [取消] [新增]   │
└──────────────────────────────┘
```

#### 欄位

| 欄位 | 類型 | 必填 | 限制 | 行為 |
|---|---|---|---|---|
| 病歷號 | `TextField` | 是 | 英文字母與數字，最多 20 個字，輸入框不接受超過的字（REQ-PAT-003 AC4、AC5） | 開啟時取得焦點 |
| 姓名 | `TextField` | 是 | 最多 50 個字，輸入框不接受超過的字（REQ-PAT-003 AC4） | — |
| 新增 | `SubmitButton` | — | — | — |

#### 畫面行為

- 按「取消」或關閉對話框時不新增；再次開啟時欄位是空的
- 新增成功後的行為見 REQ-PAT-003 AC1

## 5. 做法

- 病歷號在後端轉成大寫後才檢查與儲存：大小寫不同的病歷號視為同一個，唯一約束才擋得住
- 搜尋時把輸入轉成大寫，用部分符合查詢：病歷號已經都是大寫
- 排序依 `createdAt` 由新到舊，相同時再依 `id`：時間相同的資料換頁時才不會重複或漏掉
